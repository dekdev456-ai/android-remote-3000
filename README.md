# 📱 Remote Screen :3000 (Android)

แอป Android (Kotlin) สำหรับกดเปิดเซิร์ฟเวอร์พอร์ต `3000` บนมือถือ (`http://localhost:3000` และ `http://<IP-WiFi-มือถือ>:3000`) เพื่อแสดงหน้าจอมือถือแบบเรียลไทม์บนเบราว์เซอร์คอมพิวเตอร์ และควบคุมทัช/ปัด/ปุ่มนำทางของมือถือจากคอมพิวเตอร์ได้ทันทีบน Wi-Fi วงเดียวกัน

## ฟีเจอร์หลัก
- **ปุ่มเดียวเปิดเซิร์ฟเวอร์พอร์ต 3000** (`0.0.0.0:3000`) แสดงทั้ง `http://localhost:3000` และ `http://<IP-มือถือ>:3000`
- **แชร์หน้าจอมือถือแบบเรียลไทม์** ผ่าน Android `MediaProjection` + `VirtualDisplay` (MJPEG stream หน่วงต่ำ ปรับ FPS และคุณภาพภาพจากคอมได้)
- **ควบคุมมือถือจากเบราว์เซอร์คอม** ผ่าน Android `AccessibilityService`:
  - คลิกซ้าย = แตะหน้าจอ (Tap)
  - คลิกค้างแล้วลาก = ปัดหน้าจอ (Swipe)
  - คลิกขวา / กดค้าง = Long Press
  - ลูกกลิ้งเมาส์ = เลื่อนขึ้น/ลง
  - ปุ่ม **Back / Home / Recents / แจ้งเตือน / ตั้งค่าด่วน / ล็อกจอ**
  - ส่งข้อความพิมพ์จากคีย์บอร์ดคอมไปที่ช่องพิมพ์บนมือถือ
- **ระบบรหัส PIN 6 หลัก** ป้องกันคนอื่นใน Wi-Fi เดียวกันเข้ามาควบคุม (เปิด/ปิดหรือสุ่มใหม่ได้)

## วิธีบิลด์ไฟล์ APK

### วิธีที่ 1: บิลด์ด้วย Android Studio (บนคอม)
1. เปิดโฟลเดอร์ `android-remote-3000` ด้วย **Android Studio**
2. รอ Gradle sync เสร็จ → กด **Build > Build Bundle(s) / APK(s) > Build APK(s)**
3. นำไฟล์ `app/build/outputs/apk/debug/app-debug.apk` ไปติดตั้งบนมือถือ Android (Android 8.0 ขึ้นไป)

### วิธีที่ 2: บิลด์อัตโนมัติบน GitHub Actions (ไม่ต้องลง Android Studio)
1. นำ workflow `.github/workflows/build-apk.yml` ไปไว้ที่ root ของ GitHub repo
2. Push ขึ้น GitHub → เข้าแท็บ **Actions** → ดาวน์โหลดไฟล์ **RemoteScreen3000-debug-apk** (`app-debug.apk`) มาลงมือถือได้เลย

## วิธีใช้งานบนมือถือ + คอมพิวเตอร์
1. เชื่อมต่อ **มือถือ** และ **คอมพิวเตอร์** เข้ากับ **Wi-Fi วงเดียวกัน**
2. เปิดแอป **Remote Screen :3000** บนมือถือ
3. กด **⚙️ เปิดหน้าตั้งค่า Accessibility** → เปิดสิทธิ์ให้ **Remote Screen :3000 Touch Control** (เพื่อให้คอมกดควบคุมหน้าจอได้)
4. กลับมาที่แอปแล้วกด **▶ เปิดเซิร์ฟเวอร์ + แชร์หน้าจอ (:3000)** → กดยืนยันการแชร์หน้าจอของ Android
5. บนคอมพิวเตอร์ เปิด Chrome แล้วพิมพ์ลิงก์ `http://<IP-มือถือ>:3000` ที่แสดงบนแอป → ใส่ **PIN 6 หลัก** → ดูและควบคุมหน้าจอมือถือได้ทันที!
